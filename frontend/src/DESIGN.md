# Design Overview

This document outlines the visual and interaction design for the **BatDongSan** real‑estate web platform.

## Pages
| Page | Purpose | Key Components |
|------|---------|----------------|
| **Login (signin.html)** | Authenticate users | Email & password fields, **Login** button, link to Register |
| **Register (Register.html)** | Create new accounts | Email, password, full name, role selector, **Register** button |
| **Home (home_property_search.html)** | Browse listings | Search bar, filter panel, listings grid with image cards |
| **Property Details (property_details.html)** | View a single listing | Image carousel, property info, **Contact Owner** and **Save** buttons |
| **User Profile (user_profile.html)** | View/update personal data | Email (read‑only), full name editable, role (read‑only), **Update** button |

## UI Library
- Built with **Material‑UI (MUI)** components for consistency, responsiveness, and theming.
- Icons from `@mui/icons-material`.

## Interaction Flow
1. **Unauthenticated** users land on *Login*; can navigate to *Register*.
2. After successful login, a JWT is stored in `localStorage` and the user is redirected to *Home*.
3. From *Home* users can search, filter and click a card to open *Property Details*.
4. Sellers/Brokers/Agencies see a **Create Listing** button (visible only for allowed roles) that opens a protected form.
5. The **Profile** page (accessible from the navigation menu) lets the user edit their name.

## Accessibility
- All forms have associated `<label>` elements.
- Buttons have clear accessible names.
- Color contrast follows WCAG AA.
